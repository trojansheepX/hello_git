Here are some simple steps the employee can try for the wireless mouse issue (INC102):

1. **Check the power**
   - Make sure the mouse has batteries installed correctly.
   - If it already has batteries, replace them with new ones.
   - Confirm any power switch on the mouse is turned ON.

2. **Check the USB receiver**
   - Ensure the wireless USB dongle is firmly plugged into the computer.
   - Try moving it to a different USB port.
   - If using a docking station, try plugging the dongle directly into the laptop.

3. **Confirm the mouse is connected**
   - Turn the mouse off, then back on.
   - If the mouse has a “connect” or “pair” button, press it.
   - Wait a few seconds to see if the cursor starts responding.

4. **Test on another computer**
   - Plug the mouse’s USB receiver into another computer (if available).
   - If it works there, the issue may be with the original computer’s USB ports or settings.
   - If it does not work on another computer, the mouse may be faulty.

5. **Restart the computer**
   - Save your work and reboot the computer.
   - After restarting, test the mouse again.

**Escalate to the help desk if:**
- The mouse still does not work after trying all the steps above.
- None of the USB ports recognize the mouse or other USB devices.
- The mouse works on another computer, but not on the employee’s computer.

Here are some simple steps the employee can try for incident INC104:

1. **Check printer selection**  
   - Make sure the correct office printer is selected in the print dialog.  
   - Try re-selecting it or choose it from the list again, then attempt to print.

2. **Confirm the printer is online and ready**  
   - Look at the printer’s display: check for errors like “Offline,” “Paper Jam,” “Out of Toner,” or “No Paper.”  
   - If it’s showing an error, follow the on-screen instructions (add paper, clear jam, etc.) and then try printing again.

3. **Verify network/Wi‑Fi connection on the computer**  
   - Ensure the computer is connected to the company network (Wi‑Fi or wired).  
   - If using Wi‑Fi, reconnect to the office network and try printing again.  
   - If using a cable, make sure it is securely plugged in.

4. **Restart the printer and the computer**  
   - Turn the printer off, wait 10 seconds, then turn it back on.  
   - Restart the computer.  
   - After both are back on, try printing a small test document (like a one-page file).

5. **Remove and re-add the printer**  
   - Go to the computer’s printer settings.  
   - Remove the nearby office printer from the list.  
   - Add it again using the standard company printer setup method, then test printing.

**Escalate to the help desk if:**

- The printer does not show up in the list of available printers.  
- The employee gets repeated error messages (e.g., “Access denied,” “Printer not found,” or “Print job failed”) after following the steps above.  
- Other employees can print to that same printer, but this employee still cannot.  
- The printer shows no obvious error, but no documents print after several attempts.
